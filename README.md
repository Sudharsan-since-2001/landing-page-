Ebook Landing Page

A premium, high-converting landing page for your ebook that is personalised for me.

✨ Features

- **Premium Aesthetics**: Modern dark theme with glassmorphism and smooth gradients.
- **Micro-animations**: Powered by Framer Motion for a fluid user experience.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile.
- **Lucide Icons**: Crisp, scalable icons for visual clarity.
- **Vercel Friendly**: Zero-config deployment to Vercel.

Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

Deployment (Vercel)

To deploy this landing page to Vercel:

1. Push this code to a GitHub repository.
2. Connect the repository to [Vercel](https://vercel.com).
3. Vercel will automatically detect the Vite setup and deploy it.

Alternatively, use the Vercel CLI:
```bash
npx vercel
```

Project Structure

- `public/`: Contains static assets like the book cover and the ebook PDF.
- `src/App.tsx`: The main landing page component.
- `src/index.css`: The global styles and design system.
- `src/main.tsx`: The entry point for the React application.
